ordinary 4xx and invalid JSON are not retried. POST routing remains unchanged and is
never sent through GET utility. Retried HTTP error responses are closed. KeyboardInterrupt
is not swallowed. Snapshots are written after existing successful fetch/parse paths.

is generated by judge and preserved as additive daily JSON, consumed by existing launcher
exit-3 logic. Integration regression demonstrates that error is not reported as exit 0.
No reverse dependency, global transport patch, environment credential use or TLS bypass.
